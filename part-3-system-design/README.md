# Part 3 — System Design for GenAI at Scale

**Audience**: engineers who've completed Parts 1-2. This part treats GenAI features as
distributed systems problems: multi-tenancy, database and vector-index scaling, event-driven
ingestion, availability, and serving cost at millions-of-users / tens-of-millions-of-documents
scale. Written in an HLD-interview style — requirements, estimation, component design,
trade-offs — culminating in a full capstone design.
